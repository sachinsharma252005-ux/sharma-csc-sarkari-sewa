SHARMA CSC CENTER AND SARKARI SEWA — starter website
=====================================================

Files:
- index.html: complete responsive bilingual website (Hindi/English).
- README.txt: these instructions.

Preview locally:
1. Extract the ZIP.
2. Double-click index.html to open it in your browser.

Free publishing (one option):
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. sharma-csc-sarkari-sewa.
3. Upload index.html and this README.
4. Open repository Settings -> Pages.
5. Choose Deploy from a branch, select main and /(root), then Save.
6. GitHub will show the published website URL after deployment.

You can also use a static-site host such as Netlify Drop by uploading the extracted
site folder at its official site. Hosting provider instructions may change.

Before publishing:
- Verify all contact/address details.
- Add your own logo and any additional services you actually provide.
- Keep recruitment deadlines and scheme details current; this starter links to official portals.
- This site is informational and is not an official government website.
- Do not collect Aadhaar, OTP, passwords, bank PINs, or sensitive documents through this static page.
